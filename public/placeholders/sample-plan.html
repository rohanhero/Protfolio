Build notes

NovaStore: scope, stack and shipping.

A full-stack e-commerce platform built from scratch: React storefront, Django REST API, and an admin panel with a live CMS.

ProjectOwn platform
StackReact · Django · PostgreSQL
OutcomeOpen on GitHub

01The problem

Small stores need the whole machine. A shop that only has a catalog page still takes orders by phone, tracks stock on paper, and has no admin. I wanted one build that covers the full loop: browse, buy, track, manage.

02The plan

Storefront first, then the backbone. A fast React + Vite store was mapped first, then the Django REST API with cookie-based JWT auth, then checkout, and finally the admin panel with the CMS.

Scope→ Build→ Launch?→ Live

03What was built

Two apps, one API. The customer side and the admin side both run on the same Django REST backend.
  • Animated storefront: catalog, search, wishlists, slide-out cart
  • Multi-step Cash on Delivery checkout with order tracking and returns
  • Customer dashboard with order history
  • Admin panel with a live CMS for products, orders and content
  • Cookie-based JWT auth with token rotation, rate limiting, hardened uploads

04Results

A complete reference build. NovaStore is the codebase that proves the client work: the same auth, checkout and admin patterns run in the production e-commerce site. It is public on GitHub for anyone to read.
